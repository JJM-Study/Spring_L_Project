㈜보강시스템

개발팀 · 사원/팀원
2020.03 ~ 2023.02 (3년)
대구
퇴사사유: 업직종 전환

경력 개요

생산·수불·공정 중심의 MES 환경에서 C#, Visual Basic, MSSQL 기반 유지보수 및 기능 개선 업무를 수행했습니다.
레거시 업무 시스템의 화면, 프로시저, 출력물, 집계 로직, 로그 기능, 사용자 요청 기능 등을 수정·확장하며,
복잡한 업무 흐름과 데이터 구조를 추적하고 실제 운영 가능한 형태로 개선하는 경험을 쌓았습니다.

특히 조회·집계·정산·출력·이력 기능이 많은 업무 시스템에서,
사용자 요구사항을 기능으로 구체화하고 프로시저/쿼리/화면/출력 구조를 함께 이해하며 수정해온 경험을 바탕으로,
웹 기반 특수 도메인 시스템에서도 빠르게 적응할 수 있는 기반을 갖추었습니다.

핵심 역량

생산·수불·공정 중심 업무 시스템 유지보수 및 기능 개선 경험

MSSQL 프로시저, JOIN, 임시 테이블, 조건 분기 등을 활용한 조회/집계 로직 개선 경험

화면, 출력물, 로그, 이력, 정산 기능 등 업무 밀착형 기능 구현 경험

레거시 시스템에서 영향 범위를 추적하며 안정적으로 수정하는 유지보수 역량

사용자 요청사항을 운영 가능한 기능으로 구체화하는 실무 경험

업무 흐름, 데이터 구조, 출력 구조를 디버깅과 전체 검색으로 파악하는 문제 해결 능력

스마트 사업 관련 로그인 화면, 로그 저장/조회 화면, 사용 현황 로그 기능 추가

프로시저, 테이블, 필드의 영향 범위를 전체 검색 및 디버깅으로 추적하며 안정적으로 수정

성과 및 경험

조건절/조인 구조 개선, 임시 테이블 활용, 프로시저 분리 등을 통해 유지보수성과 조회 성능 개선 경험 축적

조회·집계·정산·출력·이력 중심의 업무 기능을 다루며 실무형 도메인 시스템 감각 확보

사용자의 요청을 단순 UI 수정이 아닌 데이터 흐름과 업무 기준까지 포함해 반영하는 경험 수행

대표 수행 사례
1) 저장/출력 로그 이력 조회 기능 추가

접수번호 기준 저장/출력 이력 조회 기능 추가

사용자 ID, 사용자명, 일자, 저장/출력 구분 등 조회 항목 정의

별도 함수로 로그 조회 로직을 분리하여 후속 유지보수성 확보

2) 합계 전용 스프레드 분리 및 열 너비 동기화

가로 스크롤이 긴 조회 화면에서 합계 확인이 어렵다는 사용자 요청 반영

별도 합계 스프레드를 추가하고 열 너비를 동기화하여 사용성 개선

3) 정산일 기준 집계 기능 추가

송장일 기준이 아닌 별도 정산일 기준 집계가 가능하도록 기능 추가

기존 집계/조회 로직을 업무 기준에 맞게 수정

4) 대형 프로시저 구조 분리

기능 확장 과정에서 프로시저 크기 한계에 걸리는 문제를 구조 분리로 해결

계 처리 로직을 별도 프로시저로 분리하여 유지보수 포인트를 명확화

5) 크리스탈 레포트 비고 항목 출력 반영

입력 화면의 비고가 실제 출력물에 반영되지 않는 문제 해결

출력용 프로시저 및 테이블 구조를 추적해 출력 데이터 반영

6) DB 연결 문제 원인 추적 및 해결

분리 실행된 프로그램의 연결 문제에 대해 설정값과 실행 환경을 점검

연결 정보 반영 위치를 추적하여 문제 해결

유지보수 관점에서 외부 설정 관리 구조의 필요성을 체감

7) 스마트 사업 로그인 및 로그 관리 기능 추가

로그인 화면 추가

로그 저장용 테이블 및 조회 화면 추가

사용 현황 로그 기능 추가

운영 이력 확인을 위한 기본 관리 기능 구성

업무를 통해 익힌 점

업무 시스템 유지보수에서는 단순 코드 수정보다 영향 범위 파악이 먼저라는 점을 배웠습니다.

조회, 집계, 출력, 로그 기능은 서로 연결되어 있어 화면·DB·프로시저·출력 구조를 함께 봐야 한다는 점을 체감했습니다.

사용자 요청은 단순한 화면 수정처럼 보여도 실제로는 업무 기준과 데이터 흐름을 이해해야 반영 가능한 경우가 많았습니다.

유지보수성은 별도의 고급 개념이 아니라, 명명, 구조 분리, 영향 범위 추적, 백업 습관 같은 기본기에서 결정된다고 느꼈습니다.
